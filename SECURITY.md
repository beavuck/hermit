# Security Reporting

If you wish to report a security vulnerability -- thank you! -- we ask that you follow the following process.

We ask that you do **NOT** create a public issue in this repo about it.

Please fill out the following template:

**PROJECT**

_Confirm the URL to the project's repository._

**PUBLIC**

_Tell us whether this vulnerability has been discussed publicly already, and if so, where._

**DESCRIPTION**

_Detail as much information as you are able and willing to provide._

Please send the above, along with any other information you feel is pertinent to: beavuck.dev@gmail.com.

You will be emailed at the same time the public announcement is made.

We will let you know within a few weeks whether your report has been accepted or rejected.

We ask that you please keep the report confidential until we have made a public announcement.
